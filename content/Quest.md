I work within a proprietary quest system built into our studio's pipeline.

My process starts with the scripting. I define the quest using the system's built-in tools.

From there, I break the quest into individual steps, which serve as the building blocks for the experience I want to create.

Inside each step, I configure the requirements. These are the conditions where the player must clear it for the step to be considered complete. I can either write task descriptions and quest narrative text that the player sees in-game or keep them invisible from the player, so my role spans both system logic and storytelling.

Once the quest is mapped out, I can playtest and iterate the entire flow directly inside UE 4.
